# Teoría jurídica

La teoría jurídica constituye un espacio de investigación en el que convergen identidad, institución, normatividad y reconocimiento.

El problema jurídico puede ser abordado también como problema de constitución: cómo una persona, una institución o una relación adquieren continuidad normativa dentro de un sistema social.

## Problemas

- Identidad
- Institución
- Normatividad
- Reconocimiento
- Continuidad
- Constitución jurídica
